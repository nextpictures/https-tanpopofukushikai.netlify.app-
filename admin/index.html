                    設定

                    ① ホームページへの反映（GitHub）

                    「公開する」でホームページに出すには、GitHub の「アクセス用の鍵（トークン）」が必要です。鍵はこのパソコン（ブラウザ）の中にだけ保存されます。

                    作り方：GitHubのトークン作成画面で「Only select repositories」にこのリポジトリを選び、「Contents」を「Read and write」にして作成します。

                    ② アクセス状況（Umami）

                    Umami Cloud の「Settings」→「API keys」で作ります。このパソコンの中にだけ保存されます。

                    ③ このパソコンの閲覧を数えない

                    ④ 管理ページのパスワードを変える

                    GitHubとつながっていれば、そのまま切り替わります。つながっていないときは、書き出された「config.js」を admin フォルダに上書きしてください。
