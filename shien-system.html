Philosophy

たんぽぽの目指すもの

働くことは、
生きること。

誰もが「働きたい」「人の役に立ちたい」と考え、自分の生き方は自分で選び、決めたいと願っています。

働いて賃金を得ることで、お金の使い方や社会の仕組みを学び、自分で選び決める力が身につきます。たくさんの経験を重ねることで、たくましく健康に生きる力を育てていきます。

5 Systems

たんぽぽの支援システム

System 1

生活のサイクルを学ぶ

働くことを中心にした毎日の生活のサイクルを、一つずつ身につけていきます。

System 2

3つの労働段階

  1. 1遊び的労働

    遊び感覚で作業に取り組み、毎日働くことにつなげていく段階。

  2. 2習慣的労働

    毎日働くことが当たり前になり、仲間と協力して仕事ができる段階。

  3. 3立ち向かいの労働

    自分から積極的に仕事に取り組み、仕事が生きがいになる段階。

System 3

頑張る力をつける

毎月、短期の目標を立て、その評価によって賃金が決まります。仕事に前向きになると、生活の仕方も変わっていきます。

System 4

自分でできることを増やす

  1. 基本的な生活習慣を身につける
  2. 自分で選び、自分で決める
  3. 体調に気を配る
  4. 我慢することを覚える
  5. 自分で帰省や外出をする
  6. グループホームなどで地域生活に移る
System 5

豊かな生活

  1. 健康な生活を送る
  2. 心に余裕を持ち、他人を思いやる
  3. 高齢期を穏やかに過ごす
