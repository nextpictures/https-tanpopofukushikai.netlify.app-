たんぽぽ福祉会ホームページ　管理ページ（/admin/）の使い方
=========================================================

管理ページでは、次の3つができます。
  1. お知らせを書く（写真・PDFもいっしょに）→「公開する」でそのままホームページに出る
  2. 登録したお知らせを直す・消す（公開中／公開予定／期間終了／下書き で絞り込み）
  3. ホームページのアクセス状況を見る（見た人・地域・ヒートマップ・よく見られたページ・押されたボタン など）

サーバーのプログラム（PHP）は使いません。次の2つの無料サービスを使います。
  ・GitHub（ギットハブ）… ホームページのファイルの置き場所。お知らせの保存先
  ・Umami（ウマミ）…… アクセス解析。Cookieを使わず、個人を特定しない仕組み

---------------------------------------------------------
■ はじめの準備（1回だけ・業者さんや詳しい方にお願いしてもOK）
---------------------------------------------------------
【1】ホームページを GitHub に置いて公開する
  1. GitHub のアカウントを作り、新しいリポジトリ（例：tanpopo-website）を作る
  2. この site フォルダの中身をすべてアップロードする
  3. 公開の方法をどれか選ぶ（どれも無料で、GitHubに保存すると1〜2分で自動でホームページが更新されます）
     ・GitHub Pages（リポジトリの Settings → Pages）
     ・Cloudflare Pages ／ Netlify（GitHubのリポジトリをつなぐ）
  4. 独自ドメイン（enatanpopo.com）を、選んだサービスにつなぐ

【2】Umami を用意する
  1. https://cloud.umami.is/ でアカウントを作る（無料プランあり）
  2.「Add website」でホームページを登録し、「Website ID」を控える
  3. js/site-config.js の umamiWebsiteId に Website ID を貼る（これで記録が始まります）
  4. Umami の Settings → API keys で「APIキー」を作って控える

【3】管理ページをつなぐ
  1. https://（ホームページのアドレス）/admin/ を開く
  2. はじめのパスワードは  tanpopo2026  です（必ず変えてください）
  3. 右上の「設定」を開いて、次を入れる
     ① GitHub：ユーザー名／リポジトリ名／アクセス用の鍵（トークン）
        トークンの作り方：https://github.com/settings/personal-access-tokens/new
          ・Repository access →「Only select repositories」でこのリポジトリを選ぶ
          ・Permissions → Contents を「Read and write」
     ② Umami：ウェブサイトID／APIキー
     ③「職員が確認のために見た分を、アクセス状況から外す」にチェック
     ④ 新しいパスワードを入れる
  4.「つながるか試す」で「✓ つながりました」と出れば準備完了です
  ※ 鍵（トークン・APIキー）は、そのパソコンのブラウザの中にだけ保存されます。
    別のパソコンで使うときは、そのパソコンでも「設定」に入れてください。

---------------------------------------------------------
■ ふだんの使い方
---------------------------------------------------------
・お知らせを出す：種類を選ぶ → 日付・タイトル・本文 → 写真やPDF（5つまで）→「公開する」
・いちばん上に出したい：「いちばん上に固定する」をオン
・決まった期間だけ出したい：「配信開始」「配信終了」を入れる（「1週間」などのボタンで自動入力）
・あとで出したい：「下書きで保存」
・直す・消す：右の「登録したお知らせ」の「直す」「削除」
・ホームページへの反映がうまくいかないとき：右上の「もう一度反映する」
・GitHub につないでいないとき：右上の「ファイルで書き出す」で news.js を保存し、
  サーバーの data フォルダに上書き（写真・PDFは files フォルダへ）

・アクセス状況：期間（今日／7日間／30日間／90日間）を選ぶ
・ヒートマップ：トップページのどこまで見られたかを色で表示。
  「ホームページの上でヒートマップを見る」で、実際のページに色を重ねて見られます
・「印刷・PDFで保存」で、会議資料にできます

---------------------------------------------------------
■ 大事なファイル
---------------------------------------------------------
  data/news.js …… お知らせのデータ（管理ページが自動で書き換えます）
  files/ ……………… お知らせの写真・PDF
  admin/config.js … 管理ページのパスワード（暗号にして保存）とつなぎ先
  js/site-config.js … Umami のウェブサイトID

---------------------------------------------------------
■ 注意
---------------------------------------------------------
・管理ページのパスワードは「画面を開くための鍵」です。お知らせを書き換える力は
  GitHub の鍵（トークン）が持っているので、トークンを人に教えないでください。
・プライバシーポリシーに、次のような文を入れてください。
  「当サイトでは、サイトの改善のため、アクセス解析ツール Umami を利用しています。
   閲覧したページ、地域（市町村程度）、利用機器などを、個人を特定しない形で記録しています。
   Cookie は使用していません。」
